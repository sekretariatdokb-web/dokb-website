Program DOKB

Program yang dibangun untuk driver, organisasi, dan masa depan mobilitas Kalsel.

DOKB mengembangkan program secara terukur untuk memperkuat kapasitas driver online roda 4 dan organisasi.

Program Unggulan

Program yang mendukung penguatan driver

Program DOKB diarahkan untuk memperkuat kapasitas organisasi, kepatuhan, advokasi, dan manfaat bagi anggota.

ED
Edukasi

Ruang Edu-DOKB

Ruang pembelajaran dan informasi bagi driver agar lebih memahami aturan, operasional, keselamatan, dan perkembangan ekosistem transportasi daring.

ASK
Kepatuhan

ASK & Kepatuhan

Pendampingan informasi dan administrasi terkait Angkutan Sewa Khusus serta penguatan budaya tertib dokumen.

DB
Data

Advokasi Berbasis Data

Pengumpulan dan pengolahan informasi untuk mendukung penyampaian aspirasi dan masukan secara terukur.

Arah Pelaksanaan

Terukur dan bertahap

Pelaksanaan program disesuaikan dengan kapasitas organisasi, keputusan internal, kebutuhan anggota, serta koordinasi dengan pemangku kepentingan.

Prinsip

Manfaat nyata bagi driver

Program diarahkan pada peningkatan pengetahuan, kepatuhan, akses informasi, kekuatan data, dan kesejahteraan anggota.
