Program DOKB

Program yang dibangun untuk driver, organisasi, dan masa depan mobilitas Kalsel.

DOKB mengembangkan program secara terukur untuk memperkuat kapasitas driver online roda 4, meningkatkan kepatuhan dan keselamatan, serta berkontribusi pada ekosistem transportasi yang lebih tertib dan berkelanjutan.

Program Unggulan

Program untuk penguatan driver dan ekosistem transportasi

Program DOKB diarahkan untuk memperkuat kapasitas organisasi, edukasi, kepatuhan, keselamatan, advokasi berbasis data, serta kontribusi positif terhadap ekosistem transportasi.

ED
Edukasi

Ruang Edu-DOKB

Ruang pembelajaran dan informasi untuk meningkatkan pemahaman tentang aturan, operasional, keselamatan, literasi digital, dan perkembangan ekosistem transportasi daring.

ASK
Kepatuhan

ASK & Kepatuhan

Pendampingan informasi dan administrasi terkait Angkutan Sewa Khusus serta edukasi untuk memperkuat budaya tertib dokumen dan kepatuhan terhadap ketentuan yang berlaku.

DB
Data

Advokasi Berbasis Data

Pengumpulan dan pengolahan informasi untuk mendukung penyampaian aspirasi, kajian, dan masukan secara terukur berdasarkan data serta fakta lapangan.

Arah Pelaksanaan

Terukur dan bertahap

Pelaksanaan program disesuaikan dengan kapasitas organisasi, keputusan internal, kebutuhan yang teridentifikasi, serta koordinasi dengan pemangku kepentingan.

Dampak Program

Pengetahuan, kepatuhan, dan keselamatan

Program diarahkan pada peningkatan pengetahuan, akses informasi, kepatuhan terhadap regulasi, keselamatan, penguatan data, dan keberlanjutan driver serta kontribusi terhadap perbaikan sistem transportasi.

Informasi Program

Jadwal, persyaratan, pendaftaran, dan pelaksanaan kegiatan mengikuti pengumuman resmi Sekretariat DOKB.
